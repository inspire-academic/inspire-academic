Distance–Time Graphs

Distance–Time Graphs

GCSE Physics · Forces and Motion · Production Pilot #2 AQA · Edexcel Estimated time: 35–45 min

By the end of this lesson you will be able to read, interpret and construct distance-time graphs — and answer the question this lesson is built around: what does the shape of a distance-time graph actually tell you about how something is moving?

  • Read a distance and a time directly from a plotted point on a distance-time graph.
  • Explain what a horizontal line and a sloping line each represent about an object's motion.
  • Calculate speed from a straight-line segment's gradient, using speed = change in distance ÷ change in time.
  • Higher Combine several stages of a journey to find total distance travelled and average speed, and explain why this differs from simply averaging the individual stage speeds.
Foundation pathway — what you need to master

This lesson has one focus for you: being able to read a distance-time graph correctly, every time, without mixing up the axes or misreading what a flat or falling line means. By the end, you should be confident with:

  • Saying which axis is time and which is distance from the start, without hesitating.
  • Reading a distance and a time straight off a plotted point or line.
  • Recognising a horizontal line as "stationary" and a steeper line as "faster."
  • Calculating a speed from a straight segment using speed = change in distance ÷ change in time.
  • Explaining, for a journey that returns to the start, why the total distance travelled and the final distance from the start can be different numbers.

3Core Lesson

First, a concrete example — before any definitions

Imagine a cyclist's journey is recorded every few seconds: how far they've travelled from home at each moment. If you plotted "time" along the bottom and "distance from home" up the side, then joined the dots, you'd get a picture of the whole journey in one line — rising while they're moving, flat while they're stopped.

That picture is a distance-time graph. Reading it is really just reading two numbers at once — a time and a distance — for any point on the line. Everything else in this lesson builds on that one idea.

Before this lesson: speed, briefly recapped

You will already have an informal sense of speed from everyday life. Formally: speed = distance ÷ time, measured in metres per second (m/s) when distance is in metres and time is in seconds. This lesson doesn't re-teach speed from first principles — it teaches you to read speed directly off a graph, which turns out to be the same relationship in a visual form.

Stage 1 — What the graph shows

A distance-time graph always has time on the horizontal (x) axis and distance from a starting point on the vertical (y) axis. Every point on the line is a (time, distance) pair — at that moment, the object was that far from where it started. The line connecting the points shows that the object's position is defined continuously, not just at the moments you happened to measure it.

Key words, in plain terms

The horizontal axis is always time (like the hands of a clock moving forward). The vertical axis is always distance from wherever the object started, which is why it's sometimes labelled "distance from start" rather than just "distance." A quick check for any graph: find the axis labels first, before trying to read anything from the shape of the line.

Stage 2 — Reading simple segments

A horizontal line means distance from the start isn't changing — the object is stationary. It doesn't mean time has stopped; time keeps moving along the horizontal axis exactly as before. A straight sloping line means distance is changing at a steady rate — constant speed. Comparing two sloped lines: the steeper line always represents the greater speed, whatever the two lines' actual distances happen to be.

Stage 3 — Gradient as speed

The steepness of a line — its gradient — tells you how quickly distance changes with time. That is exactly what speed measures, so on a distance-time graph, gradient is speed. Formally, for any straight segment: speed = change in distance ÷ change in time. This is the same speed relationship recapped above — a distance-time graph is simply a picture of it.

Stage 4 — Multi-stage journeys

Real journeys are rarely one straight line. A graph can show several stages joined together — moving steadily, stopping, moving again, perhaps at a different speed, or moving back toward the start. Each straight segment is read separately, using its own change in distance and change in time — a change in gradient partway along the line simply means the object's speed changed at that moment.

Stage 5 — Story ↔ graph translation

You should be able to work in both directions: describe, in words, the motion a graph shows ("steady for 20 s, then stopped for 10 s, then a faster return"), and — the harder direction — picture roughly what a graph would look like from a description of a journey. Both directions use the same three ideas: flat = stopped, sloped = moving, steeper = faster.

Stage 6 — Deeper reasoning Higher

For a journey with several stages, the average speed for the whole journey is total distance travelled ÷ total time — not the simple average of each stage's individual speed. These two calculations only agree when every stage lasts exactly the same amount of time; otherwise, a stage that lasts longer should count for more in a genuine average, which only total-distance-over-total-time correctly does. Total distance travelled also always adds the length of every stage, including a return leg — it is not the same number as the final distance from the start, which can be smaller (even zero) if the object has moved back toward where it began.

5Worked Examples

Example 0 — the simplest case, one step at a time Foundation

Question
A go-kart's distance-time graph is a straight line from (0 s, 0 m) to (10 s, 50 m). How far had the go-kart travelled after 4 s?
Step 1
Find 4 s on the time axis (the bottom, horizontal one).
Step 2
From 4 s, trace straight up until you reach the line.
Step 3
From that point on the line, trace straight across to the distance axis (the side, vertical one).
Step 4
Read the value where you land — that's the distance after 4 s.
Check with the formula
Speed = 50 ÷ 10 = 5 m/s. Distance after 4 s = 5 × 4 = 20 m — the same answer, confirming the graph and the formula always agree.
Answer
20 m.

Common wrong approach: tracing across before up (swapping the order of Steps 2 and 3) — always go time → up → line → across → distance, in that exact order, so you read the point actually above your chosen time, not a different one.

Example 1 — Reading a point from the graph

Question
Graph 1 shows a cyclist's distance-time graph: a straight line from (0 s, 0 m) to (60 s, 300 m). What distance had the cyclist covered after 24 s?
What matters
The line is straight from the origin, so the cyclist moves at one steady speed throughout.
Reasoning
Speed = 300 ÷ 60 = 5 m/s. Distance after 24 s = speed × time.
Calculation
5 × 24 = 120
Answer
120 m.

Common wrong approach: misreading the value off the wrong axis, or miscounting gridlines and quoting "24 m" or a nearby-but-wrong distance. Always trace up from the correct time value to the line, then straight across to the distance axis — never estimate by eye alone when gridlines are available.

Example 2 — Interpreting a horizontal segment

Question
Graph 2 shows a jogger's distance-time graph rising to 200 m over the first 40 s, then flat until 60 s. Describe what happens between 40 s and 60 s, and state the jogger's speed during this time.
What matters
The line is perfectly horizontal for this interval — distance from the start does not change.
Reasoning
Speed = change in distance ÷ change in time = 0 ÷ 20.
Calculation
0 ÷ 20 = 0
Answer
The jogger is stationary; speed = 0 m/s.

Common wrong approach: treating the flat section as if the jogger's story has paused or "time has stopped" — the horizontal line still moves forward along the time axis exactly as before; only the jogger's own motion has stopped.

Example 3 — Calculating speed from a gradient

Question
A car's distance-time graph is a straight line: it covers 240 m in 20 s at a steady speed. Calculate the car's speed.
What matters
Δdistance = 240 m, Δtime = 20 s.
Reasoning
Speed = Δdistance ÷ Δtime.
Calculation
240 ÷ 20 = 12
Answer
12 m/s.

Common wrong approach: dividing time by distance (20 ÷ 240 ≈ 0.083) instead of distance by time — always check the formula reads speed = distance ÷ time, never the reverse.

Example 4 — Comparing two gradients

Question
Graph 3 shows two cyclists over the same 40 s. Cyclist A reaches 400 m; Cyclist B reaches 200 m. Which cyclist is faster, and by how much?
What matters
Both journeys share the same start and the same 40 s duration, so their speeds are directly comparable.
Reasoning
Speed A = 400 ÷ 40. Speed B = 200 ÷ 40. Compare the two.
Calculation
Speed A = 10 m/s. Speed B = 5 m/s. Difference = 10 − 5 = 5 m/s.
Answer
Cyclist A is faster, by 5 m/s.

Common wrong approach: comparing only the final distances ("A travelled twice as far") without converting to a speed — distance alone doesn't tell you the rate unless the times are also compared, which is exactly what the gradient does automatically.

Example 5 — Interpreting a multi-stage journey

Question
Graph 4 shows a cyclist's delivery journey: out at a steady rate to 150 m over 30 s, stationary for 20 s, then back to 0 m over the final 30 s. Calculate the speed for each moving stage, and state the total distance travelled for the whole 80 s journey.
What matters
Three separate stages, each read on its own: outward (0–30 s), stationary (30–50 s), return (50–80 s).
Reasoning
Outward speed = 150 ÷ 30. Return speed = 150 ÷ 30 (same magnitude, opposite direction — back toward the start). Total distance travelled adds every stage's own distance, including the return leg.
Calculation
Outward: 150 ÷ 30 = 5 m/s. Return: 150 ÷ 30 = 5 m/s. Total distance = 150 + 0 + 150 = 300 m.
Answer
Both moving stages are 5 m/s; total distance travelled = 300 m, even though the distance from the start at the end is 0 m.

Common wrong approach: reading the graph's final height (0 m) as "the cyclist didn't travel anywhere" — confusing the final distance from the start with the total distance actually travelled. This is the same distinction Lesson 1 (Distance and Displacement) makes between distance and displacement: "distance from start" behaves like a displacement magnitude here, while "total distance travelled" is the true distance, and the two are only equal when a journey never doubles back on itself.

Example 6 — Spot the error Higher

Question
A van's distance-time graph rises from 0 m to 200 m in 25 s, stays flat for 15 s, then falls from 200 m to 50 m in 20 s. A student is asked to calculate the van's average speed for the whole 60 s journey, and writes: "The van ends up 50 m from the depot, so average speed = 50 ÷ 60 ≈ 0.83 m/s."
The student's error
They used the final distance from the depot (50 m) instead of the total distance actually travelled — average speed for a whole journey always uses total distance travelled ÷ total time, per Stage 6.
Correct method
Total distance travelled = 200 (outward) + 0 (stationary) + 150 (return, since 200 − 50 = 150) = 350 m. Total time = 60 s.
Calculation
350 ÷ 60 ≈ 5.83 m/s (3 s.f.)
Answer
≈ 5.83 m/s — not the student's 0.83 m/s.

6Misconception Clinic

Nine specific wrong beliefs this topic invites — each one named, shown why it's wrong, and tied back to a graph or worked example above.

"A horizontal line means the object has stopped existing, or that time has stopped."
A horizontal line means the object's distance from the start isn't changing — it is stationary. Time continues to pass; only the object's position stops changing. See Graph 2's flat section from 40 s to 60 s, and Worked Example 2.
"A steeper line automatically means the object went further overall."
Steepness (gradient) represents speed, not total distance. A steep line reaching a small distance in a short time can represent a faster speed than a shallow line reaching a larger distance over a much longer time. Compare speeds by calculating gradients — see Graph 3 and Worked Example 4, where the comparison only works cleanly because both journeys share the same time axis.
"The vertical axis shows speed."
The vertical axis always shows distance from the starting point. Speed is never read directly off a distance-time graph — it must be calculated from the gradient (Stage 3).
"A falling line means the object had a negative speed."
Speed is a scalar quantity and can never be negative (see Lesson 1: Distance and Displacement). A falling "distance from start" line means the object is physically moving back toward its starting point, at a real, positive speed equal to the size of that segment's gradient — see Graph 4's return leg.
"Graph height and graph gradient mean the same thing."
Height (the y-value) tells you how far from the start the object currently is. Gradient (steepness) tells you how fast it's moving right now. A graph can be high but flat (far away and stationary) or low but steep (close to the start but moving quickly) — the two are independent.
"Equal time intervals always cover equal distances."
This is only true when speed is constant throughout. On a graph with changing gradient, equal time intervals can cover very different distances — see Independent Practice, where a jogger covers 40 m in one 10 s interval and only 20 m in the next.
"A flat section means the object hasn't travelled anywhere at all yet."
A flat section only means no distance is covered during that interval — the object could already be a long way from the start (a high, flat line), not necessarily at the very beginning. Always check the y-value where the flat section actually sits, not just that it's flat.
"The visual angle of a line can be compared between different graphs just by looking."
Steepness is only meaningful within one graph's own declared scale. Two different distance-time graphs drawn with different axis scales can make identical speeds look completely different, or different speeds look the same. Always compare gradients using the actual numbers (Δdistance ÷ Δtime), never by eye across two separately-scaled graphs.
Higher "Average speed for a whole journey can always be found by averaging each stage's individual speed."
This only works when every stage lasts exactly the same amount of time. In general, average speed = total distance travelled ÷ total time — a longer-lasting stage should count for more, which only the total-over-total method correctly captures. See Stage 6 and Guided Practice Q3, where averaging the two stage speeds (6 m/s and 2 m/s → 4 m/s) gives a different, wrong answer from the correct 3.71 m/s.

Extra support Warm-up. A delivery cyclist's distance-time graph is a straight line from (0 s, 0 m) to (20 s, 100 m). Describe what this tells you about the cyclist's motion, and calculate the speed.
Hint 1
A straight line from the origin means the distance increases at a steady rate — constant speed, no stops.
Hint 2
speed = distance ÷ time = 100 ÷ 20.
Full solution
The cyclist moves at a steady 5 m/s; the straight line confirms the speed never changes over this 20 s.
1. A graph shows a horizontal line at 80 m from 10 s to 25 s. What is happening during this time, and what is the object's speed?
Hint 1
A horizontal line means the distance from the start isn't changing.
Hint 2
speed = change in distance ÷ change in time = 0 ÷ 15.
Full solution
The object is stationary (parked/resting) for these 15 seconds; its speed is 0 m/s, since the distance from the start doesn't change.
2. Between 0 s and 10 s, a runner's distance from the start rises from 0 m to 60 m on a straight line. Between 10 s and 25 s, it rises further, reaching 150 m on another straight line. Calculate the runner's speed in each stage, and state which stage was faster.
Hint 0 Foundation
Treat each stage separately: work out Δdistance ÷ Δtime for stage 1 first, then do exactly the same for stage 2, before comparing the two answers.
Hint 1
Stage 1: Δd = 60 − 0 = 60 m, Δt = 10 − 0 = 10 s.
Hint 2
Stage 2: Δd = 150 − 60 = 90 m, Δt = 25 − 10 = 15 s.
Full solution
Stage 1 speed = 60 ÷ 10 = 6 m/s. Stage 2 speed = 90 ÷ 15 = 6 m/s. Both stages have the same speed — the line's steepness doesn't change, even though it's drawn as two separate segments starting from different points.
Higher 3. A cyclist's distance-time graph shows: 0–15 s steady from 0 m to 90 m, then 15–35 s steady from 90 m to 130 m. Calculate the average speed for the whole 35 s journey, and explain why it is not simply the average of the two stage speeds.
Hint 1
Average speed for the whole journey = total distance ÷ total time, not the average of the two individual speeds.
Hint 2
Total distance = 130 m (the final distance from the start, since this is one continuous outward journey). Total time = 35 s.
Full solution
Average speed = 130 ÷ 35 ≈ 3.71 m/s (3 s.f.). This is not the simple average of 6 m/s and 2 m/s (stage speeds: 90÷15=6 m/s, 40÷20=2 m/s, average 4 m/s), because the two stages lasted different amounts of time — the slower stage lasted longer, pulling the true average down below the simple midpoint.
Higher 4. A drone's distance-time graph rises steadily from 0 m to 240 m over 40 s, stays at 240 m for 10 s, then falls steadily back to 0 m over the next 20 s. Calculate the drone's speed for each moving stage, and its total distance travelled for the whole 70 s flight.
Hint 1
Treat the outward and return legs separately — each has its own Δdistance and Δtime.
Hint 2
Total distance travelled adds the size of every leg, including the return leg — it does not subtract anything, even though the graph itself falls back toward zero.
Full solution
Outward speed = 240 ÷ 40 = 6 m/s. Return speed = 240 ÷ 20 = 12 m/s — twice as fast returning. Total distance travelled = 240 + 0 + 240 = 480 m, even though the distance from the start at the end is 0 m.

speed = distance ÷ time = 100 ÷ 251
= 4 m/s1

Model answer: 4 m/s. Examiner note: full marks need both the correct method line and the correctly-unitted final answer — a bare "4" without "m/s" would typically lose the final mark.
Q2 · Describe · 3 marksCORE_ALL_TIERS
A distance-time graph shows a runner's distance from the start rising steadily from 0 m to 100 m over the first 20 s, remaining flat at 100 m for the next 15 s, then rising steadily again to 160 m over the final 15 s. Describe the runner's motion throughout the journey.
Runner moves at a steady speed away from the start for the first 20 s1
Runner is stationary for the next 15 s1
Runner moves at a steady, slower speed away from the start for the final 15 s1
Model answer & examiner note
Model answer: steady motion away from the start for 20 s (5 m/s), then stationary for 15 s, then steady motion again at a slower speed (4 m/s) for the final 15 s. Examiner note: full marks require identifying all three distinct stages, not just describing the overall upward trend.
Q3 · Calculate · 3 marksCORE_ALL_TIERS
A hiker's distance-time graph shows two stages: 0 m to 900 m over the first 1800 s, then a rest, then 900 m to 1500 m over a further 1200 s. Calculate the hiker's speed, in m/s, for the second (moving) stage.
Δd = 1500 − 900 = 600 m1
Δt = 1200 s1
speed = 600 ÷ 1200 = 0.5 m/s1
Model answer & examiner note
Model answer: 0.5 m/s. Examiner note: marks are available for correctly identifying Δd and Δt separately, even if the final division is wrong — always show this working, not just a final number.

Graph 5 shows a delivery van's distance-time graph: distance from depot rises from 0 m to 300 m over the first 20 s, remains at 300 m for the next 30 s, falls to 100 m over the following 40 s, remains at 100 m for a further 20 s, then falls to 0 m over the final 20 s. Calculate the van's average speed for the whole 130 s journey, using total distance travelled, not final distance from the depot.
Identifies total distance travelled = 300 + 0 + 200 + 0 + 100 = 600 m (not final distance from depot, 0 m)2
Identifies total time = 130 s1
average speed = 600 ÷ 130 ≈ 4.62 m/s (3 s.f.)1

Model answer: ≈ 4.62 m/s. Examiner note: the most common error is using the final distance from the depot (0 m) instead of summing the size of every leg — exactly Graph 5's own teaching point, and the reason this question carries 2 marks for the total-distance step alone.
Q5 · Evaluate · 3 marksCORE_ALL_TIERS
Two students each travel from home to school and describe their journeys using distance-time graphs. Student A's line is steeper than Student B's, but Student A's journey is drawn for a shorter time. A classmate claims: "Student A must live further from school, because their graph is steeper." Evaluate this claim.
Steepness represents speed, not distance1
A steeper line only shows Student A travelled faster, not further1
Correctly concludes the claim is not necessarily true — the final height reached, not the gradient, shows how far each student lives1
Model answer & examiner note
Model answer: the claim is incorrect — steepness shows speed, not distance. Student A may simply be faster, or may live exactly as far (or even closer); the final distance value reached, not the gradient, is what indicates distance from school. Examiner note: "Evaluate" expects a judgement (the claim is/isn't justified) with reasoning, not just a restatement of the definitions.
Q6 · Identify and explain · 3 marksCORE_ALL_TIERS
A student's working for a distance-time graph question is shown: "The graph falls from 300 m to 100 m between 40 s and 70 s, so the object's speed is −6.67 m/s." Identify the error in this working and explain the correct approach.
Identifies the error: speed has been given a negative sign1
Explains speed is a scalar quantity and is never negative1
States the correct approach: speed = (300−100)/(70−40) = 200/30 ≈ 6.67 m/s, describing the direction in words rather than with a minus sign1
Model answer & examiner note
Model answer: the error is writing the speed as negative. Speed is a scalar and cannot be negative — the calculation itself (200 ÷ 30 ≈ 6.67 m/s) is correct, but the falling line should be described as "moving back toward the start," not as a negative speed. Examiner note: this is the single most common error this topic produces — directly tests Misconception Clinic card 4.
