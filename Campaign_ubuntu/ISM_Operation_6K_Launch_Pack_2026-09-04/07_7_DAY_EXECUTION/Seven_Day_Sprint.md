# ISM — 7-DAY ACQUISITION SPRINT

## DAY 1 — FRIDAY 4 SEPTEMBER
**Goal: go live and start conversations.**
- Publish/hand off landing page
- Activate diagnostic intake
- Put first 25 warm families into tracker
- Send 20 personal parent messages
- Ask 5 strong parents/contacts for two introductions each
- Contact 5 church/community leaders
- Book first parent reviews
- Post one WhatsApp Status
**Do not:** redesign logos, build unrelated app features, perfect long PDFs.

## DAY 2 — SATURDAY
**Goal: convert attention into diagnostics.**
- Follow up all Day-1 replies
- Help interested families start/complete diagnostic
- Add next 20–25 prospects
- Send 20 more direct contacts
- Run first 5–10 parent review calls if diagnostic data is ready
- Capture every objection verbatim
- Secure first paid enrolments

## DAY 3 — SUNDAY
**Goal: community distribution + system repair.**
- Follow up church/community leaders
- Send ready-made forwardable notice
- Review funnel drop-offs
- Fix only conversion-blocking defects
- Prepare Monday follow-up list
- Do not spam church groups; use permission-based distribution

## DAY 4 — MONDAY
**Goal: second acquisition wave.**
- 20 contacts
- 5+ follow-ups
- 5 review calls
- Ask every enrolled family for two introductions
- Publish one useful GCSE misconception/diagnostic post with CTA
- Calculate current MRR and enrolment conversion

## DAY 5 — TUESDAY
**Goal: sharpen offer from evidence.**
- Review top five parent objections
- Update FAQ/landing copy
- Identify which tier parents are actually choosing
- Check delivery capacity created by each enrolment
- Recruit/assign tutor capacity if Plus demand is material
- 20 contacts + 5 follow-ups

## DAY 6 — WEDNESDAY
**Goal: partner multiplication.**
- Second wave to churches/community groups
- Ask warm leaders for direct introductions to 2–3 families
- Create source codes/fields so partner leads are attributable
- Run review calls
- Continue referral asks

## DAY 7 — THURSDAY
**Goal: numbers, not feelings.**
Produce a one-page scorecard:
- total prospects
- contacted
- replies
- diagnostics started/completed
- reviews held
- offers
- paid students
- MRR
- cash collected
- delivery cost committed
- acquisition cost
- biggest bottleneck

### Decision rules
If contacts are low → prospecting problem.
If replies are low → message/audience problem.
If diagnostics are low → CTA/friction problem.
If reviews are low → follow-up problem.
If reviews happen but nobody buys → offer/price/trust problem.
If people buy but delivery becomes chaotic → capacity/system problem.

# 30-DAY CHECKPOINT
Do not ask “Did we work hard?”
Ask:
1. How many paying students?
2. What is MRR?
3. What is actual gross contribution after direct delivery cost?
4. Which acquisition source converts best?
5. What is churn/refund behaviour?
6. How many founder-hours are required per student?
7. What must be delegated before the next 20 students?
