# ISM MASTERY DIAGNOSTIC — CONVERSION FUNNEL SPEC

## Purpose
The diagnostic is both an educational tool and the primary acquisition mechanism. It must create genuine value before asking for payment.

## Parent journey
1. Landing page CTA: **Start the Mastery Diagnostic**
2. Parent intake form
3. Student completes age/tier-appropriate diagnostic
4. System creates a concise parent-facing findings report
5. Parent books/receives a 10-minute review
6. Inspire recommends Founding/Core/Plus
7. Parent enrols and recurring payment is established
8. Student enters onboarding

## Minimum intake fields
- Parent/guardian full name
- Email
- Mobile number
- Child first name
- Year group: 9 / 10 / 11
- School (optional)
- Exam board(s), if known
- Maths tier, if known
- Science route: Combined / Triple / unsure
- Subjects causing most concern
- Parent's single biggest concern
- Current working grades **only if parent knows them**
- Target grades
- Preferred contact method
- Consent to contact regarding ISM

## Diagnostic design
Do NOT make a 90-minute monster test. Initial diagnostic should feel achievable.
Suggested v1:
- 10–15 min parent/student intake
- 25–35 min academic diagnostic
- Mix of retrieval, calculation, application and misconception probes
- Use existing Inspire question-bank assets where available
- Branch by Year / Foundation-Higher where defensible
- Do not market an algorithmic "predicted grade" unless validated

## Parent report — one page
Headline: **[Student]’s Inspire Mastery Snapshot**
1. Strengths observed
2. Priority gaps
3. Exam/application vulnerabilities
4. Recommended next 4 weeks
5. Recommended ISM pathway
6. CTA: **Book/Confirm Your ISM Place**

Use plain language. Avoid shame-based wording.

## Recommended routing logic for v1
- **Core:** student needs structured weekly teaching + clinic + practice
- **Plus:** evidence of significant gaps requiring an additional targeted small-group intervention
- **Founding:** commercial eligibility, not academic severity

A human should approve the recommendation until enough real data exists to automate safely.

## Follow-up SLA
- Diagnostic started but not completed: follow up within 24 hours
- Diagnostic completed: parent contacted same day where practical
- Review completed but not enrolled: follow up at 24 hours and 72 hours
- No response: one final courteous follow-up after 7 days

## Funnel metrics
Track weekly:
- Landing visitors
- Diagnostic starts
- Diagnostic completions
- Parent reviews booked
- Parent reviews attended
- Paid enrolments
- Conversion: visitor → diagnostic
- Conversion: diagnostic → review
- Conversion: review → paid
- Acquisition source
- Monthly recurring revenue
- Refund/cancellation rate
- Tutor delivery cost per student
