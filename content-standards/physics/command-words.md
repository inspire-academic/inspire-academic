# Command words

AQA GCSE science command words, with what each demands of the student and how Inspire uses it. Summarised by Inspire; AQA's own glossary (aqa.org.uk, "command words" for GCSE sciences) is the authority if they ever differ.

| Command word | The student must | Typical marks | Inspire use |
|---|---|---|---|
| Name / Give / Write | State a fact or term, no explanation | 1 | recall items |
| Identify | Name or otherwise characterise from given information | 1 | data / diagram items |
| Choose | Select from a range of alternatives | 1 | MCQ |
| Complete | Fill in missing information (table, sentence, diagram) | 1–2 | practice |
| Label | Provide appropriate names on a diagram | 1–2 | practice |
| Define | Give the meaning of a term precisely | 1–2 | only for terms the spec requires (never thermal conductivity) |
| Describe | Recall facts, events or processes accurately; no reason needed | 2–4 | conceptual items |
| Explain | Give reasons for, or causes of, something; "because" is required | 2–6 | mastery-check and application |
| Compare | Describe similarities and/or differences; both sides must be referred to | 2–4 | application |
| Suggest | Apply knowledge to an unfamiliar situation; more than one answer may be credit-worthy | 1–3 | application (transfer) |
| Predict | Give a plausible outcome | 1–2 | practice |
| Calculate | Work out a numerical value; working expected | 2–4 | numeric items; marks for substitution, rearrangement, answer, unit |
| Determine | Use given data or information to obtain an answer | 2–3 | data items |
| Estimate | Assign an approximate value | 1–2 | order-of-magnitude items |
| Show (that) | Provide structured evidence leading to a given result | 2–3 | Higher application; the answer is given, so marks are for the method |
| Evaluate | Use information to consider evidence for and against, and reach a judgement | 4–6 | energy resources (4.1.3) |
| Justify | Use evidence from the information supplied to support an answer | 2–3 | application |
| Plan / Design | Set out a method or a system | 4–6 | required practical items |
| Plot / Draw / Sketch | Graph work to the precision indicated | 2–4 | graph items |
| Measure / Use | Take a reading / base the answer on the given information | 1–2 | practical and data items |

## Mark allocation principles (for application and constructed items)

- **Calculate, 2–3 marks:** 1 for correct substitution (or rearrangement); 1 for the answer; 1 for a correct unit where the unit is not given. Allow "error carried forward" from an earlier step.
- **Explain, 2 marks:** one mark per linked point; an unexplained statement earns at most the first mark.
- **6-mark extended response:** levels of response (level 1: 1–2, level 2: 3–4, level 3: 5–6); the indicative content is listed; the level depends on the logical chain, not on the number of points.
- The command word must match the demand: "describe" questions must not require explanation; "calculate" must not be worth 1 mark if two steps are needed.
