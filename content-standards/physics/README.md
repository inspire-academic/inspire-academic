# Physics content standards (reference pack)

The standards every Inspire Physics item is written and reviewed against. The Physics Subject Expert Review Agent (`.claude/agents/physics-subject-reviewer.md`) reads this whole folder before reviewing, and every review report records the git commit of this folder it used. Change a standard here, and the next review uses it.

| File | What it fixes |
|---|---|
| `aqa-8463-energy.md` | What the AQA specification requires for Energy (4.1), its boundaries, and the required practicals |
| `equations.md` | Which equations students must recall and which are given, with symbols, units and tier |
| `maths-and-units.md` | GCSE mathematical demand, SI units, prefixes, significant figures and rounding conventions |
| `command-words.md` | AQA command words and what each demands, including marks |
| `terminology.md` | Accepted and rejected scientific language |
| `evidence-classes.md` | Diagnostic, practice, mastery check, retrieval, application and practical items, with difficulty bands and the mastery rules they feed |
| `item-writing-standards.md` | How Inspire items are written: stems, options, distractors, feedback, templates, contexts |
| `review-rubric.md` | The review criteria, severities, decision rules and report format |
| `concept-pack-format.md` | How a concept pack is written (items, calculation blocks, templates) and what the automated checks enforce |

Canonical concept definitions and the misconception library live with the curriculum source (`curriculum/physics/`) and are part of the reviewer's input too.

**Source and copyright.** Specification content is summarised and referenced by statement number from AQA GCSE Physics 8463 (version 1.1, 30 September 2019, aqa.org.uk/8463), for internal authoring use. Past-paper questions are never copied into this folder or into drafting prompts.

**Scope.** Currently Energy (4.1) and the Physicist's Toolkit skills. Electricity (4.2) is added before Electricity content is drafted.
